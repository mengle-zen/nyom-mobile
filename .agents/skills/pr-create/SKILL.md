# PR 생성

- 사용자가 PR 생성을 요청한 범위에서 작업한다. 별도 브랜치(Codex는 `codex/` 접두사)로 올리고, PR을 자동으로 병합하지 않는다.
- `.github/pull_request_template.md`를 사용해 제목과 본문을 한국어로 작성한다. 문제와 수정 후 동작을 간결하게 적고, 별도 검증 섹션이나 테스트 결과 목록은 넣지 않는다.
- 관련 이슈를 연결한다. 이슈를 완전히 해결할 때만 `Closes #번호`를 쓴다.
- UI 변경에는 가능하면 실제 실행 스크린샷을 넣는다. 버그 수정은 가능하면 같은 화면과 조건의 **As-is / To-be**를 나란히 비교한다. 캡처하지 못했다면 이유를 적는다.
- 비밀정보·개인정보가 없는 캡처를 GitHub PR에 직접 첨부하고, 본문에서 이미지가 렌더링되는지 확인한다. PR 검토용 스크린샷은 저장소에 커밋하지 않는다. 첨부가 어려우면 이유를 적는다.
- PR 생성 후 링크와 검증 결과, 남은 한계를 사용자에게 알려준다.
